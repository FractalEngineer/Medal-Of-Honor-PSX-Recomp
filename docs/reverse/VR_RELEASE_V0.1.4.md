This update adds a laser sight and easier machine gun aiming.

- Added a barrel laser: hold the right grip and the beam ends on the surface it hits.
- The right grip no longer triggers the native aim.
- A mounted machine gun now aims with one stick: hold the left grip.
- Added tracking for the passport and the silenced pistol's suppressor.
- Added a launcher per OpenXR runtime (VDXR, SteamVR, Oculus) in place of the single generic launcher.
